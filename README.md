# Phishing Awareness Quiz

An interactive browser quiz that trains users to recognize phishing emails, SMS messages, and malicious URLs. Each answer comes with an explanation of the red flags.

**Live demo:** https://fevenadane586-design.github.io/phishing-awareness-quiz/

## Features

- 8 realistic scenarios: emails, URLs, and an SMS
- Instant feedback with an explanation after every answer
- Score and advice at the end, with a retry option
- Runs entirely in the browser, with nothing stored or sent

## Red flags covered

- Look-alike domains (for example `paypa1` with a number 1)
- Real brand names placed in a subdomain to disguise the true domain
- Urgency and threats ("verify within 24 hours")
- Requests for credentials, gift cards, or payments
- Shortened links that hide the destination
- Generic greetings and mismatched sender domains

## What I learned

- How common phishing techniques work and how to recognize them
- How to read a URL to find its real domain
- How to build an interactive quiz with HTML, CSS, and JavaScript

## Future improvements
